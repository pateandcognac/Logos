This directory contains old Logos "diaries".  Many dating back years!
They are so old and different than the current Logos framework that viewing them directly can be confusing rather than helpful.
So! We have processed them to extract useful memories, but without technical details.
These extracted memories have been already added to the logoi collective vector db, using `import_diary_memories.py`
No further processing needs to be done on these files. They are saved for posterity.
