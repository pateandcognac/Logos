def expressive_gaze(

    pos2: Tuple[Optional[float], Optional[float]],

### Why these are tailored for Flash/Flash-Lite:
1. **Explicit API Checks in Comments:** By making the model write "Let me check my API docs... right, `approach_astra_detection` takes...", you force the model's cross-attention heads to actively search the `<arche>` context block before it generates the Python function call. This drastically reduces hallucinated function names.
2. **"Oops" and "Wait" Mechanics:** Example 3 demonstrates a mid-thought course correction. This teaches the model that it doesn't have to rigidly stick to its first generated token; if it realizes mid-generation that a path is blocked, it can use Python comments to pivot its strategy *before* calling the action.
3. **Verbose Phantasmata logic:** Example 2 explicitly forces the model to reason about the Z-axis math (`key_world_point[2] + 1.0`) in the comment/code structure, setting it up for success when interacting with 3D space.
